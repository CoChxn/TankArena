# Tank Arena와 diep.io 비교 분석

- 작성일: 2026-10-24. 기준 코드: 저장소의 현재 `game.js`.
- 코드는 바꾸지 않았고, 이 파일 하나만 새로 만들었습니다. 시뮬레이션 테스트는 돌리지 않았습니다.

## 0. 조사 방법과 한계

**웹 접근 상태**
- 공식 위키(diepio.fandom.com, diepio-archive.fandom.com)와 위키백과는 이 환경에서 열리지 않았습니다(DNS 오류, 프록시 403).
- 그래서 원작 수치는 GitHub에 공개된 역분석 자료 두 곳을 근거로 했습니다.
  - **[DID]** diepindepth: 원작 프로토콜·물리·능력치를 역분석한 문서.
  - **[DC]** diepcustom: 원작을 다시 구현한 서버 코드.
- 둘 다 **공식 자료가 아닙니다**. 따라서 이 문서의 "확인됨"은 "역분석 자료에 그렇게 적혀 있음"을 뜻합니다. 원작 서버 코드로 검증된 값이라는 뜻이 아닙니다.
- [DC]의 레벨 점수 식에는 작성자가 "완전히 정확하지 않다"는 주석을 달아 두었습니다. 탄 퍼짐 식에도 "No this is not correct"라는 주석이 있습니다.

**확신도 표기**

| 표기 | 뜻 |
|---|---|
| 확인됨(역분석) | [DID]나 [DC] 페이지에서 직접 읽은 값 |
| 추정 | 그 값으로 제가 계산했거나 단위를 환산한 값 |
| 미확인(기억 기반) | 웹에서 확인하지 못하고 제 기억에 의존한 내용 |
| 확인 못함 | 자료를 찾지 못한 항목 |

**우리 게임 쪽 근거**
- `game.js`의 `CFG`와 코드, 그리고 `docs/build_doc.js`의 문장입니다.
- `game.js` 주석이나 문서에 이유가 적힌 차이는 **(의도된 차이 가능)** 으로 표시했습니다.

**단위 환산**
- 원작의 탱크 기본 반지름은 25√2 ≈ 35.36(원작 단위)이고, 우리 게임은 `CFG.playerR = 24`(px)입니다. 따라서 원작 1단위 ≈ 우리 0.679px로 놓았습니다(추정).
- 1틱은 원작 40ms(25틱/초)이고([DC] `src/config.ts`), 우리 게임 `TICK = 0.04`와 같습니다.

**작업 지시와 다른 점**
- 지시에는 "우리는 Tank, Twin, Sniper, Machine Gun, Flank Guard만 있음"이라고 되어 있었습니다.
- 현재 코드에는 **30레벨 클래스 8종**도 있습니다(`CFG.classUp30`, `CFG.classes`): Triple Shot, Twin Flank, Quad Tank, Tri-Angle, Assassin, Hunter, Destroyer, Gunner.
- 아래 비교는 현재 코드를 기준으로 했습니다.

**공통 기호** (특별히 다시 적지 않으면 아래 뜻입니다)

| 기호 | 뜻 |
|---|---|
| P | 해당 능력치에 넣은 포인트 수(0~7) |
| L | 탱크 레벨(1~45) |
| M | 클래스(탱크 종류)별 배율 |

## 1. 능력치 8종

**우리 게임의 기본 식**
- 각 능력치 값 = `base + per × P`입니다(`CFG.stats`).
- 재생, 재장전, 몸통 피해는 코드의 다른 곳에서 따로 계산합니다.

| 항목 | 원작(수치) | 우리 게임(파일·CFG·값) | 차이 | 근거·확신도 |

| 총 포인트와 지급 레벨 | L≤28: L−1개. 이후 `floor(L/3)+18` (30, 33, …, 45에서 1개씩), 45레벨 합계 33 | `pointsFor(L)`: L≤28은 L−1, 29는 27, 이후 `28 + floor((L−30)/3)`, 45레벨 = 33 | 같음(29~45 모든 레벨에서 값 일치, 추정 계산) | 확인됨(역분석) [S6] |

**(의도된 차이 가능)**
- 총알 속도 배율 `bulletSpeedMul 0.7`과 크기 배율 `bulletSizeMul 1.3`.
  - `game.js`의 주석은 "diep.io는 클래스마다 총알 속도·크기를 배율로 정함"이라고 설명합니다.
  - 문서 변경 이력에는 "총알 기본 속도를 0.7배, 기본 크기를 1.3배로 변경"이라고 조정한 것으로 적혀 있습니다.
- 레벨에 따른 감속.
  - 우리 코드 주석은 "diep.io: 레벨당 크기·총알 크기 +1%, 기본 속도는 그만큼 감소"이고, 크기와 같은 1%를 썼습니다.
  - 역분석 자료의 이동 감속은 1.5%/레벨입니다. 일부러 다르게 한 것인지 근거로 착각한 것인지는 확인하지 못했습니다.

### 3.3 반동 상세 (2026-10-26 추가 조사)

> **반영됨(2026-10-26):** 이 조사를 바탕으로 `CFG.recoilMode = 'diep'`(포신별 고정 반동, `recoilPer 32.5`, 포신 `rec` = 아래 원작 값)을 구현했습니다. 이전 식은 `recoilMode = 'legacy'`로 되돌릴 수 있습니다. 아래 표의 "우리" 값은 **변경 전(legacy)** 기준입니다. diep 방식에서 지표 ③(연사 중 이동 방해)은 1레벨에서 원작과 같게 맞췄고(추정 환산), 45레벨에서는 이동 감속 차이 때문에 원작보다 약 20% 작습니다(`recoilLevelComp`로 보정 가능, 기본 꺼짐).

**자료**
- 원작 쪽은 [S3] `tankdefs.json` 원문(포신별 `recoil`)과 [S2] physics 문서 §3.6, [S7] `Barrel.ts`, [DC] `src/Entity/Object.ts`를 직접 내려받아 읽었습니다(확인됨, 역분석).
- `tankdefs.json`이 원작 클라이언트에서 추출한 자료라는 점은 미확인(기억 기반)입니다.

**원작의 반동 규칙** (확인됨, 역분석)
- 한 발을 쏠 때마다 탱크 속도에 `2 × B_R`(원작 단위/틱)을 포신 반대 방향으로 더합니다.
  - B_R: 그 포신의 반동 값(`tankdefs.json`의 `recoil`).
  - 근거: [S2] §3.6 `b_R = 2 * B_R`, [S7] `addVelocity(angle + π, recoil * 2)`.
- 이 값은 **고정**입니다. 총알 크기·속도·피해, 능력치 포인트, 탱크 크기(레벨)와 상관이 없습니다.
- 마찰은 틱마다 속도의 10%입니다([DC] `Object.ts`). 따라서 한 발로 밀리는 총 거리는 `10 × 2 × B_R`입니다.
- 탱크의 이동 가속 `A = 2.55 × 1.07^P ÷ 1.015^(L−1)`(P: 이동 속도 포인트, L: 레벨)는 레벨이 오를수록 줄어듭니다. 반동은 그대로이므로 **고레벨일수록 반동이 상대적으로 커집니다**(45레벨에서 1.925배).

**원작 포신별 반동 값** ([S3] 원문)

| 클래스 | 포신별 recoil | 비고 |
|---|---|---|
| Tank, Machine Gun, Flank Guard, Triple Shot, Twin Flank, Quad Tank | 1 | MG는 재장전이 0.5배라 시간당 반동은 Tank의 2배 |
| Twin | 0.75 × 2문 | |
| Sniper | 3 | 재장전 1.5배 |
| Assassin | 3 | 재장전 2배 |
| Hunter | 0.3 × 2문 | 재장전 2.5배 |
| Destroyer | 15 | 재장전 4배 |
| Gunner | 0.2 × 4문 | |
| Tri-Angle | 앞 0.2, 뒤 2.5 × 2문(210°, 149°) | 뒤 포신이 탱크를 앞으로 미는 추진 장치 |
| (참고) Annihilator 17, Ranger 3, Booster 앞 0.2·뒤 2.5×2·0.2×2 | | |

**우리 게임의 반동 규칙** (`game.js` `Player.shoot`)
- 식: `반동 속도 dv = min(recoilMax 150, recoilK 2.7 × recoilMul 0.5 × 클래스 recoil × m² × √(총알 속도 × recoilV 480))` (px/초)
  - m: `spec.size ÷ bulletSizeMul ÷ 탱크 반지름` = `8×1.01^(L−1) ÷ (24×1.01^(L−1))` = **항상 1/3**
  - 총알 속도: `(480 + 45 × 탄속 포인트) × 클래스 speed`(px/초, `bulletSpeedMul`를 곱하기 전)
  - 클래스 recoil: `CFG.classes`의 값. 포신별 값은 없습니다.
- 마찰은 `drag 4.5`/초입니다. 따라서 한 발로 밀리는 총 거리는 `dv ÷ 4.5`입니다(두 단계 지연은 총 거리를 바꾸지 않음).
- 레벨이 올라도 dv는 같고 최고 속도는 `1.01^(L−1)`로 줄어서, 45레벨에서 반동이 상대적으로 1.549배 커집니다.
- 원작과 달리 **탄속 포인트가 반동을 키웁니다**(7포인트에서 √(795/480) = 1.29배).

**같은 기준으로 계산한 비교** (모두 추정 계산. 계산 스크립트는 저장소 밖 임시 폴더에서 돌림)
- 지표 ①: 한 발 반동 속도 ÷ 탱크 최고 속도
- 지표 ②: 한 발로 밀리는 거리 ÷ 탱크 반지름
- 지표 ③: 앞으로 계속 쏠 때의 평균 반동 가속 ÷ 이동 가속. 음수는 뒤로 밀린다는 뜻이고, −100%보다 작으면 앞으로 이동 키를 눌러도 뒤로 밀립니다.
- 조건 1: 1레벨, 모든 포인트 0. 조건 2: 45레벨, 재장전·탄속 7포인트, 이동 0포인트.

| 클래스 | ① 원작 / 우리 (1레벨) | ② 원작 / 우리 (1레벨) | ③ 원작 / 우리 (1레벨) | ③ 원작 / 우리 (45레벨) |
|---|---|---|---|---|
| Tank | 8% / 31% | 0.57 / 0.67 | −5% / −12% | −19% / −43% |
| Twin | 6% / 8% | 0.42 / 0.17 | −8% / −6% | −28% / −22% |
| Sniper | 24% / 9% | 1.70 / 0.20 | −10% / −2% | −38% / −9% |
| Machine Gun | 8% / 13% | 0.57 / 0.27 | −10% / −9% | −38% / −35% |
| Triple Shot | 8% / 9% | 0.57 / 0.20 | −13% / −5% | −45% / −20% |
| Assassin | 24% / 10% | 1.70 / 0.20 | −8% / −2% | −28% / −7% |
| Hunter | 2% / 9% | 0.17 / 0.20 | −1% / −3% | −5% / −10% |
| Destroyer | 118% / 65% (상한) | 8.49 / 1.39 | −20% / −6% | −71% / −18% |
| Gunner | 2% / 13% | 0.11 / 0.27 | −4% / −30% | −15% / **−121%** |

**정리**
1. **"순서가 반대"는 일부만 맞습니다.**
   - 원작의 한 발 세기 순서는 Tank(8%) < Sniper(24%) < Destroyer(118%)입니다.
   - 우리는 Sniper(9%) < Tank(31%) < Destroyer(65%)입니다.
   - 즉 Sniper·Assassin만 Tank보다 약해져 순서가 뒤집혔습니다. Destroyer는 여전히 가장 크지만 Tank와의 차이가 원작 15배에서 우리 약 2배로 줄었습니다.
2. **기본 Tank의 반동은 원작과 비슷합니다.** 한 발에 밀리는 거리는 반지름의 0.57배와 0.67배로 비슷합니다. 다만 우리는 마찰이 강하고(시상수 0.22초 대 원작 약 0.38초) 최고 속도에 비해 반동 속도가 커서, 짧고 세게 튀는 느낌입니다.
3. **Destroyer는 원작 대비 약 1/6입니다.**
   - 한 발 거리가 원작은 반지름의 8.5배, 우리는 1.4배입니다.
   - 우리 값은 `recoilMax 150` 상한에 이미 걸려 있습니다(상한이 없으면 150.6). 그래서 탄속 포인트도, 클래스 recoil을 2.5보다 올리는 것도 효과가 없습니다.
   - 원작의 "Destroyer로 뒤로 쏘아 빠르게 이동·도주" 운용은 우리 게임에서 거의 불가능합니다.
4. **Sniper·Assassin은 원작 대비 약 1/8입니다.** 원작에서는 쏠 때마다 뚜렷하게 밀리는 것이 저격형의 약점인데, 우리 게임에서는 거의 밀리지 않습니다.
5. **Tri-Angle의 추진력이 약합니다.** 원작은 45레벨에서 이동 가속의 78%를 더해 주는 추진 클래스인데, 우리는 33%입니다. 원작은 뒤 포신 반동(2.5)이 앞 포신(0.2)보다 훨씬 크지만, 우리는 포신별 반동 값이 없어 앞뒤 모두 클래스 값 1을 씁니다.
6. **Gunner의 반동이 원작보다 크게 셉니다(의심 사항).**
   - 45레벨, 재장전·탄속 7포인트 조건에서 계속 쏘면 앞으로 이동 키를 눌러도 뒤로 밀립니다(−121%). 원작은 −15%입니다.
   - 원인으로 보이는 점: `Player.shoot`의 `m`은 `spec.size`(클래스 공통 크기)를 쓰고, 포신별 총알 크기 `barrel.size`(Gunner 0.55, Destroyer 2, Twin 0.85 등)를 쓰지 않습니다.
   - 문서 4.6절의 "총알 크기 ÷ 탱크 반지름"이라는 설명과 실제 코드가 다릅니다. 포신 크기를 넣으면 Gunner는 0.55² ≈ 0.30배가 되어 약 −36%입니다(계산).
   - 일부러 그렇게 만든 것인지는 주석이나 이력에서 확인하지 못했습니다. 이번 조사에서는 코드를 고치지 않았습니다.
7. **값을 정한 경위:**
   - Twin·Sniper `recoil 0.25`, MG `0.4`는 저장소 첫 커밋(`45226b5`)부터 있었고, 이유를 적은 주석이나 문서는 없습니다.
   - 30레벨 클래스 값(Assassin·Hunter 0.25, Destroyer 2.5 "반동 큼(추정)", Gunner 0.4, Triple 0.3)은 커밋 `a728ac9`, `184feaf`에서 추가되었고, 주석에 "추정"이라고 적혀 있습니다.
   - 따라서 원작 값을 근거로 정한 값이 아니라 **추정값**이며, 의도된 차이라는 근거는 찾지 못했습니다.
   - 문서 변경 이력의 "반동의 레벨 보정을 없애고 모든 레벨에 50% 적용"(`recoilMul`)은 일부러 조정한 기록입니다.

**(의도된 차이 가능)**
- 30레벨 클래스의 재장전·피해 값 일부는 `game.js` 주석에 "추정(DPS를 기존 클래스에 맞춤)"으로 적혀 있습니다(Triple, Twin Flank, Gunner, Destroyer 등).

**`CFG.bulletRange` 식**
- `Dmin = Dt × tMin(1.5) × 클래스 rangeMin`
- `Dmax = Dt × (tMaxA 0.8 + tMaxB 0.25 × P') × 클래스 rangeMax`
- 기호의 뜻:
  - Dt: 틱당 피해
  - P': 총알 체력 ÷ `bulletHp`
  - rangeMin, rangeMax: 클래스별 배율(기본 1)

**전투 우위 R 식** (`CFG.botFight`)
- 식: `R = (내 체력% × 내 공격력) ÷ (상대 체력% × 상대 공격력)`
- 공격력 = `(1 + (레벨 − 1) ÷ offBase 14)^offPow 3`
- 기호의 뜻:
  - 체력%: 체력 막대에 보이는 비율
  - 레벨: 각 탱크의 레벨
- R이 싸움 기준 `thrMul 0.85 × (needBase 1.6 − needBold 1.25 × 대담함)` 이상이면 싸웁니다.

## 차이 요약 (게임 플레이 영향이 큰 순서, 큰 차이 10개)

순서는 제 판단입니다(측정 아님).

1. **상대가 사람이 아니라 AI 봇입니다.**
   - 원작은 실제 멀티플레이이고, 일반 AI 탱크는 알려진 바가 없습니다(미확인, 기억 기반).
   - 우리는 10~20대 봇과 성격·전투 우위 R 기반 AI를 씁니다.
   - 난이도와 경험 전체를 좌우합니다.
2. **클래스 수가 크게 부족합니다.**
   - 우리는 13개, 원작은 약 50개입니다.
   - 45레벨 전직, Smasher, 드론·트랩·자동 포탑·투명 계열이 없습니다.
   - 30레벨 이후 성장 목표가 적습니다. `game.js` 주석상 일부러 제외했으므로 의도된 차이일 가능성이 있습니다.
3. **처치 점수가 다릅니다.**
   - 원작은 상대의 레벨 점수 전체를 줍니다([DC] 기준).
   - 우리는 `40 + 상대 점수 × 0.5`입니다.
   - 탱크 사냥의 가치가 원작의 약 절반이라 파밍 위주 플레이가 됩니다.
4. **반동의 클래스별 차이가 원작보다 훨씬 작습니다** (3.3에서 다시 계산).
   - 한 발 반동 속도 ÷ 최고 속도(1레벨): 원작은 Tank 8%, Sniper 24%, Destroyer 118%이고, 우리는 Tank 31%, Sniper 9%, Destroyer 65%입니다(상한에 걸림).
   - Sniper·Assassin은 Tank보다 약해져 순서가 뒤집혔습니다. Destroyer의 반동 이동과 Tri-Angle의 추진력은 원작보다 훨씬 약합니다.
   - Gunner는 포신별 총알 크기가 반동 계산에 들어가지 않아 원작보다 크게 셉니다(의심 사항).
5. **급속 회복이 원작(30초)보다 2배 빨리 시작합니다(우리 15초).**
   - 교전 사이 회복이 빨라 지구전과 도주가 유리해집니다.
6. **레벨에 따른 이동 감속이 약하고 시야는 더 넓어집니다.**
   - 45레벨 속도: 원작 0.519배, 우리 0.645배(추정 계산).
   - 45레벨 보이는 너비: 원작 약 1.245배, 우리 1.40배(추정 계산).
   - 고레벨 탱크가 원작보다 빠르고 멀리 봅니다.
7. **원작에 없는 총알 피해 범위 제한이 있습니다(`bulletRange`).**
   - 한 발이 탱크에 주는 총 피해에 하한과 상한이 있습니다.
   - 관통력 높은 빌드의 "한 발 다단 히트" 위력이 원작과 달라집니다.
8. **도형 배치가 다릅니다.**
   - 둥지 모양(원 대 정사각형)과 알파 생성 방식이 다릅니다(항상 1개 대 오각형의 5%).
   - 크래셔 구역과 시야가 다릅니다(650px 대 약 1,360px 환산).
   - 우리에게만 군집과 육각형이 있습니다. 파밍 동선과 위험 지역이 원작과 다릅니다.
9. **부활 레벨이 20~35레벨 구간에서 원작보다 2~4레벨 낮습니다.**
   - 예: 25레벨에서 죽으면 원작 16, 우리 12.
   - 중반 사망의 손해가 큽니다.
10. **맵 크기가 인원에 따라 바뀌고, 미니맵에 모든 봇이 표시됩니다.**
    - 원작 FFA는 고정 크기입니다([DC] 기준).
    - 원작 미니맵에 적이 나오는지는 미확인(기억 기반)입니다. 표시되지 않는다면 우리 플레이어가 정보 면에서 크게 유리합니다.
